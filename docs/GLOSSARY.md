# Glossary

| English / code term | Indonesian | Definition |
|---|---|---|
| Document Intelligence | Kecerdasan Dokumen | Conversion of documents into structured, evidence-backed information. |
| Ingestion | Penerimaan Dokumen | Controlled entry into the processing platform. |
| Classification | Klasifikasi | Prediction of document family/type/subtype. |
| Extraction | Ekstraksi | Identification of fields/entities. |
| Normalization | Normalisasi | Conversion of raw values into canonical values. |
| Evidence | Bukti/Sumber Temuan | Page/text/region supporting a result. |
| Confidence | Tingkat Keyakinan | Calibrated score associated with a prediction. |
| Finding | Temuan | Structured validation/reconciliation result. |
| Ground Truth | Data Acuan Terverifikasi | Human-verified target for evaluation/training. |
| Human-in-the-Loop | Tinjauan Manusia | Human confirmation/correction when required. |
| Taxonomy | Taksonomi Dokumen | Controlled hierarchy of document classes. |
| OOD | Di luar distribusi | Input unlike known/training distributions. |
| STP | Pemrosesan tanpa review manual | Straight-through processing. |
| Tenant | Pelanggan/organisasi terisolasi | Logical customer boundary. |
| RFP | Permintaan Pembayaran | Reference Request for Payment process. |

Code/API/schema/event identifiers use English.
